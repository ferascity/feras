Step 1 of 2 • Market Lifecycle

Create Devnet Market

Creates an open pari-mutuel market PDA and its associated test-USDC vault. The canonical match ID becomes part of the on-chain PDA and cannot be changed later.

Unique 3-96 character slug matching the backend match
Human-readable title displayed in the Arena
Quick presets:
Deploying A Game Step-by-Step
  1. Create the backend match: npm run create:match -- --id <id> --title "<title>" --lock-at "<iso-time>"
  2. Connect your Platform Authority wallet below and click Review and create market.
  3. After confirmation, link it into PostgreSQL using the CLI command: npm run confirm:market -- --id <match-id> --market <market-pda> --vault <vault-ata> --signature <sig> --command CREATE
Step 2 of 2 • Market Lifecycle

Lock Devnet Market

Locks the market at or after its scheduled lock time, permanently halting incoming positions so the authoritative Stockfish coordinator can begin live execution.

Only executable at or after the on-chain lock timestamp
Starting The Game
  1. Wait until the lock time is reached on-chain.
  2. Connect Platform Authority wallet and click Review and lock market.
  3. Confirm the lock in backend: npm run confirm:market -- --id <match-id> --market <market-pda> --vault <vault-ata> --signature <sig> --command LOCK
  4. The backend coordinator immediately transitions the match to LIVE and begins executing Stockfish moves!
