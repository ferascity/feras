Upgrade Authority Handoff

Connect only the configured new upgrade-authority wallet. The local server partially signs the checked loader instruction with the temporary CLI authority; your extension provides the required second signature.

Initialize Platform Configuration

Connect only the configured platform-authority wallet. It pays account rent and becomes the on-chain Feras configuration authority.

Create Devnet Market

Creates one open market and its program-owned Devnet USDC vault. The canonical match ID becomes part of the on-chain PDA and cannot be edited later.

Distribute Devnet USDC

Funds a tester wallet from the fixed Devnet test-USDC supply. It cannot mint tokens and signs only from the configured distribution wallet.
